The Problem

Smallholder farmers and agronomists make crop selection and soil amendment decisions largely based on intuition and regional heuristics. Soil sensor data is increasingly available - pH meters, NPK sensors, moisture probes - but the gap between raw readings and actionable decisions remains wide.

Existing tools either require expensive lab analysis, operate as static lookup tables with no personalization or are black-box enterprise systems inaccessible to independent growers. The result: suboptimal crop choices, over-application of amendments and avoidable yield loss.

"What if a farmer could point a sensor at their soil and instantly know not just what's wrong - but exactly what to do about it, for a specific crop, with a cost estimate attached?"

02

Approach

CACTUS - Crop Adaptive Cultivation & Terrain Understanding System - is built around a core insight: soil suitability prediction benefits from two fundamentally different signal types. Sensor readings capture point-in-time chemistry. Satellite imagery captures spatial texture, drainage patterns and land history that sensors alone miss.

Rather than treating these as separate tools, CACTUS fuses them in a single neural architecture trained end-to-end - learning to weight each signal based on what the data demands.

01
Soil Sensor Ingestion
CSV readings from field sensors (pH, moisture %, N/P/K ppm, temperature) are loaded server-side and rotated per session to simulate a live IoT feed.
02
Tabular MLP Branch
A 3-layer dense network (Dense 64, 32, 16) processes normalized sensor features. Batch normalization and dropout regularize against noisy field readings.
03
Spatial CNN Branch
A convolutional network processes 64x64 RGB satellite patches over the field. Three Conv2D layers with max-pooling extract spatial texture features - drainage, compaction and historical land use signals invisible to point sensors.
04
Fusion & Suitability Output
Both branch outputs are concatenated (48-dim vector) and passed through a fusion Dense(32) layer, terminating in a sigmoid neuron outputting a suitability score in [0, 1] per crop.
05
Amendment Recommendation Engine
NPK deficits are computed against crop-specific targets. A rule-based selector ranks amendments by strength and cost, producing quantity estimates, cost ranges and time-to-effect guidance.
03

Model Architecture

The model is designed so that the spatial CNN branch can be zeroed out when satellite imagery is unavailable - the tabular branch alone retains the majority of predictive signal. This makes the system deployable in low-connectivity field environments while remaining architecturally ready for full fusion as data pipelines mature.

// CACTUS - Dual-Path CNN + MLP Fusion Architecture TABULAR BRANCH (soil sensor readings) Input -> [pH, moisture%, N, P, K, temp] shape (6,) Layer1 -> Dense(64, relu) + BatchNorm + Dropout(0.3) Layer2 -> Dense(32, relu) + BatchNorm + Dropout(0.2) Layer3 -> Dense(16, relu) SPATIAL BRANCH (64x64 RGB satellite patch) Input -> Tensor [H=64, W=64, C=3] Conv1 -> Conv2D(32, 3x3, relu) + MaxPool(2x2) Conv2 -> Conv2D(64, 3x3, relu) + MaxPool(2x2) Conv3 -> Conv2D(64, 3x3, relu) + GlobalAvgPool Dense -> Dense(32, relu) FUSION LAYER Concat -> [tabular(16), spatial(32)] shape (48,) Fuse -> Dense(32, relu) + Dropout(0.2) Output -> Dense(1, sigmoid) suitability_score in [0, 1] x100 -> displayed as % match Loss : BinaryCrossentropy Optimizer : Adam(lr = 1e-3) Weights : 75% tabular signal · 25% spatial signal

04

What Was Built

Beyond the model, CACTUS is a fully functional full-stack web application with five distinct views, live reactive state and a production-grade design system.

Live Soil Dashboard
Arc gauges update in real time as sliders are dragged. ML inference re-runs on every soil change with animated score transitions.
Analytics Tab
Recharts radar chart of soil profile, bar chart comparing ML scores across all crops and NPK target vs. current breakdown.
Amendment Engine
Identifies top two NPK deficits, ranks amendments by strength and cost and outputs quantity, cost range and time-to-effect per recommendation.
Planting Calendar
Visual month-by-month planting and harvest window grid across all supported crops, color-coded by crop identity.
Sensor Rotation
A server-side cursor cycles through soil CSV rows on each refresh, simulating a rotating live IoT sensor feed without a database.
Settings & Transparency
Model weights, scoring parameters and data source status are exposed in a settings panel - no black-box opacity.
